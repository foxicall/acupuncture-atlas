# 腧穴定位方法總論
- **來源檔案**：3.5腧穴定位方法.mp4
- **核心主旨**：系統講解針灸學中腧穴的四大定位方法（體表標誌、骨度分寸、手指同身寸、簡便取穴法），並強調「骨度分寸定位法」的核心地位與取穴規範。

---

## 一、 核心要點精華（Key Summary）
- **理論/診斷要點**：腧穴定位是針灸臨床取穴的基礎，人體穴位定位分為四個主要體系。其中，「體表標誌」依賴人體解剖特徵；「骨度分寸」是將人體骨節劃分為固定比例的絕對標準；「手指同身寸」是作為輔助的相對標準；「簡便取穴」則為特定穴位的快速定位技巧。
- **臨床辨證思維**：在臨床實際操作中，應以「骨度分寸定位法」為最根本、最準確的依據。「手指同身寸」僅適用於一次性取穴到位或作為微調（加減），絕不可用於長距離的疊加取穴，以免因誤差累積而導致定位失準。
- **高頻重點/考點**：
  1. **活動標誌定位**：必須透過特定的肢體動作（如屈曲、握拳、旋轉）才能顯現的標誌（如養老穴、曲池穴）。
  2. **手指同身寸標準**：拇指同身寸（1寸）、中指同身寸（1寸，取內側橫紋頭距離）、一夫法（3寸，四指併攏以中指近端指間關節為準）。
  3. **定位禁忌**：手指同身寸絕對禁止疊加使用（如：不可用兩個「一夫法」去測量6寸的距離）。
  4. **骨度分寸**：影片特別點出肘橫紋至腕橫紋為12寸，此為基礎常識，要求重點記憶各部位的骨度分寸表。

## 五、 臨床安全、禁忌與異常處理（Clinical Safety）
- **取穴誤差防範（核心強調）**：
  - 講師特別警告，**「手指同身寸」不可用於疊加取穴**。例如若穴位位於腕橫紋上3寸，可用「一夫法」一次定位；但若穴位在腕橫紋上6寸，絕不可以使用兩次「一夫法」疊加尋找，疊加會產生嚴重的尺寸變形與誤差，必須改用「骨度分寸定位法」。
- **簡便取穴法的規範**：
  - 臨床使用的「簡便取穴法」必須是**教科書上明確認可的方法**。民間流傳的取穴法若未經權威認證，容易造成定位偏差，進而影響臨床療效與針刺安全，不建議隨意使用。

## 六、 詳細課堂章節筆記
- **[00:00 - 02:52] 第一大類：體表標誌定位法**：
  - 分為「固定標誌」與「活動標誌」。
  - **固定標誌**：指人體固定不變的標誌，如五官（鼻尖、下巴）、毛髮（髮際邊緣）、指甲、乳頭、肚臍（神闕穴）等。
  - **活動標誌**：必須透過關節或肌肉的活動才能呈現的凹陷、皺褶或肌腱。例如：定腕橫紋必須彎曲手腕；定內關必須握拳用力使兩筋（橈側腕屈肌腱與掌長肌腱）顯露；定養老穴必須旋轉手腕使骨縫凹陷出現。
- **[02:53 - 04:04] 第二大類：骨度分寸定位法（最重要）**：
  - 祖先將人體各個骨節之間的長度，按比例折算成固定的「寸」。這是所有定位法中最權威、最精準的基礎。
  - 舉例：從肘橫紋（肘關節）到腕橫紋（腕關節）的固定長度定義為 **12寸**。利用這個比例，可以準確找出上肢段的所有穴位。
  - 講師展示了頭面部、胸腹部、脊背部、上肢與下肢的骨度分寸表，並強調課後必須重點記憶。
- **[04:05 - 05:46] 第三大類：手指同身寸定位法**：
  - 基於患者自身手指尺寸的測量法，常用有三種：
    1. **拇指同身寸**：拇指指間關節的寬度為1寸。
    2. **中指同身寸**：中指彎曲時，中指中節兩個內側橫紋頭之間的距離為1寸。
    3. **一夫法（橫指同身寸）**：將食、中、無名、小指四指併攏，以中指近端指間關節橫紋的水平寬度為3寸。
  - **臨床重點提示**：此法僅限於「一次取穴到位」或「骨度分寸基礎上的微調（加減）」，嚴禁使用此法進行長距離的連續疊加測量。
- **[05:47 - 07:18] 第四大類：簡便取穴定位法與總結**：
  - 介紹了百會、章門、列缺的簡便取穴動作要領。
  - 總結四大定位法，並再次強調學習針灸必須將**「骨度分寸定位法」**作為重中之重來掌握。

## 七、 課後複習與臨床實踐建議（Actionable Takeaways）
- **重點複習方向**：
  - 課後必須熟記《骨度分寸表》（常用骨度折量寸），特別是頭部（如前髮際至後髮際12寸）、胸腹（兩乳頭間8寸）、上肢（腋前紋頭至肘橫紋9寸，肘至腕12寸）、下肢（髀樞至膝中19寸，膝中至外踝尖16寸）等高頻考點。
- **臨床操作建議**：
  - 練習「活動標誌定位法」時，初學者應在自己或同學身上反覆模擬關節的屈伸與旋轉，親手觸摸肌腱的隆起與骨縫凹陷的變化（如尋找養老穴的骨裂隙）。
  - 在臨床操作時，務必記住「手指同身寸」指的是**患者本身**的手指比例，若醫師與患者體型差異較大（如成人與兒童），醫師不可直接用自己的手指為患者量度，應以患者的手指尺寸為準，或嚴格使用骨度分寸結合彈性比例尺（皮尺）來定位。
