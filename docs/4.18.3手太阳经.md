# 手太陽小腸經重點腧穴：少澤、後溪
- **來源檔案**：4.18.3手太阳经.mp4
- **核心主旨**：本講次詳細闡述手太陽小腸經上兩個核心腧穴（少澤、後溪）的體表定位、三層主治規律（近治、遠治、特殊作用）以及相應的針刺與放血操作規範，並結合特定穴理論解析其臨床效用機制。

---

## 一、 核心要點精華（Key Summary）
- **理論/診斷要點**：穴位主治規律被嚴謹地劃分為「近治作用」、「遠治作用」與「特殊作用」。兩穴均具備明顯的遠治作用（反映小腸經循行至頭面五官的特性）；其特殊作用則高度依賴於其「特定穴」屬性（井穴主急熱、八脈交會穴通督脈主腰背脊柱）。
- **臨床辨證思維**：授課者強調「循經辨證」與「交會辨證」結合的思維。例如，治療腰背痛時選用後溪，正是因為後溪作為八脈交會穴通於督脈，而督脈循行於腰背正中，故能治督脈所過之病候。治療乳疾或急熱證時，則利用少澤身為「井穴」主深熱、開竅、通絡的特性。
- **高頻重點/考點**：
  1. **少澤**的特殊主治：乳疾（乳癰、乳汁少）與急熱證（昏迷、熱病）。
  2. **後溪**的定位姿勢（微握拳）與特殊主治（腰背痛、瘧疾、癲狂癇）。
  3. **少澤**常規不用毫針，而多選用三棱針「點刺放血」。
  4. **後溪**治療手指攣痛時的高階手法：「透刺合谷」。

## 四、 刺灸手法與操作規範
- **進針與行針手法**：
  - **後溪穴**：採用毫針直刺，深度為0.5~1.0寸。針對手部局部的嚴重攣痛，講師特別提到可採用「一針透兩穴」的**透刺法**（後溪透合谷），以增強疏通經絡局部氣血的效果。
- **補瀉手法與留針時間**：影片未具體提及常規提插撚轉補瀉及留針時間。
- **艾灸/特殊療法**：
  - **少澤穴（刺絡放血法）**：講師特別強調，少澤穴若不用常規針刺，非常適合使用**三棱針**進行**點刺出血**。此特殊療法是中醫臨床治療急證、熱證（如高熱昏迷、咽喉紅腫熱痛）的核心泄熱降逆手法。

## 五、 臨床安全、禁忌與異常處理（Clinical Safety）
- **解剖危險區與刺灸深度禁忌**：少澤位於指尖末梢，神經末梢極為豐富，痛覺敏銳，進針（0.1寸）或點刺時需手法敏捷，減輕患者痛苦。後溪透合谷時需掌握針尖方向，避免刺傷手掌深部動脈弓（影片未詳述，屬臨床常規延伸）。

- **[00:00 - 01:50] 基礎定位知識與腧穴取法**：
  - 介紹了尋找手部穴位的重要體表標誌：小指指甲、掌橫紋頭、赤白肉際（手背側與掌側皮膚交界處）、第五掌指關節。
  - 詳解少澤（兩線交點法）與後溪（微握拳，尋找動態關節後方）的精準定位技巧。
- **[01:51 - 03:00] 腧穴主治病候解析**：
  - 按照「近治、遠治、特殊」三大框架梳理。
  - 少澤以遠治和特殊作用（乳疾、急熱證）為主；後溪三層作用均顯著，涵蓋手局部、頭項五官以及神志、腰背、瘧疾等廣泛領域。
- **[03:01 - 03:39] 針刺具體操作示範**：
  - 演示少澤的斜刺與三棱針點刺；演示後溪的直刺與透刺合谷的方向。
- **[03:40 - 05:01] 核心理論提煉與總結**：
  - **遠治原理**：兩穴的遠治作用均源於「經脈循行所聯繫的部位」，即小腸經循行於頭面、五官。
  - **特定穴原理**：
    - **後溪**：為八脈交會穴，通於督脈。因此治腰背痛既是遠端取穴，也是督脈病候的特殊對證治療（多用於脊柱正中線的疼痛）。
    - **少澤**：為井穴。井穴主「深熱」，故多用於熱證、急證。且少澤因部位表淺，極少發生局部病損，故「近治作用不明顯」。

- **臨床操作建議**：
  - **尋穴練習**：在自己或同學手上，練習「微握拳」狀態下辨認第五掌指關節的活動界限，準確尋找「赤白肉際」與「掌橫紋頭」的交匯點（後溪）。
  - **放血練習**：在矽膠練習模具上，練習三棱針點刺的「穩、準、快」手法，體會點刺不宜過深但須見血的力道掌握。
