# 足少阳经重点腧穴（环跳、阳陵泉、足临泣）
- **來源檔案**：4.19.3足少阳经.mp4
- **核心主旨**：本講次詳細解析了足少陽膽經三個核心重點腧穴（環跳、陽陵泉、足臨泣）的骨性解剖標誌、體表定位方法、臨床主治特點（近治、遠治與特殊作用）及標準針刺操作規範。

## 一、 核心要點精華（Key Summary）
- **理論/診斷要點**：課程總結了腧穴主治的兩大規律：一是「腧穴所在，主治所及」，如環跳、陽陵泉對下肢及局部關節的近治作用；二是「經脈所過，主治所及」，如陽陵泉與足臨泣在治療膽腑病候（黃疸、口苦）及少陽經脈循行部位（偏頭痛、目赤、脅肋痛）的遠端療效。
- **臨床辨證思維**：在取穴與治療上強調依賴精確的解剖標誌（如股骨大轉子、骶管裂孔、腓骨小頭等）。對於不同的病症需求，需採用不同的針刺深度與感應，例如治療坐骨神經痛時，環跳穴需深刺並追求下行放射感。
- **高頻重點/考點**：
  1. 環跳穴的「三分法」定位（外1/3與內2/3交點）及側臥屈股的取穴體位。
  2. 三穴主治作用的對比（環跳偏於局部近治，陽陵泉與足臨泣兼具明顯的遠治與特殊作用）。
  3. 特定穴屬性與特殊治療作用（如陽陵泉治筋脈拘攣，足臨泣治乳腺疾病及月經不調）。

- **[01:51 - 03:00] 主治病證對比與辨證**：
  - 透過表格對比三穴功效。環跳專攻局部與下肢經脈病（腰腿痛、痿痹）；陽陵泉發揮少陽經與膽腑的遠治作用（黃疸、口苦、脅痛）及治筋病的特殊作用（拘攣、驚風）；足臨泣除經脈遠治外，特別強調其在婦科（月經不調）及乳腺疾病（乳癰、乳少）中的特殊應用。

  - 講解了三個穴位的具體進針深度與方向。環跳因部位豐厚需深刺 2-3 寸並要求神經放射感；陽陵泉常規直刺 1-1.5 寸；足臨泣因位於足背，僅直刺 0.3-0.5 寸。

## 七、 課後複習與臨床實踐建議（Actionable Takeaways）
- **歌訣或記憶口訣**：（影片未提及，但建議學員結合《四總穴歌》的衍生或《馬丹陽天星十二穴治雜病歌》來加深記憶，例如：「環跳折腰莫能顧，冷風濕痹痛難當」、「陽陵居膝下，外廉一寸中... 偏風與半身，舉步不能起」）。
- **臨床操作建議**：
  1. **觸診訓練**：初學者應在互相練習中，準確摸清「股骨大轉子最高點」與「骶管裂孔」這兩個關鍵點，確保環跳穴連線取穴的精準度。
  2. **針感控制**：環跳穴的放射感是臨床療效的關鍵。練習時需體會針尖穿透臀大肌進入深層組織的手感，切忌盲目暴力提插。
  3. **配穴思維**：在處理偏頭痛或脅肋痛時，可嘗試將陽陵泉與足臨泣相配伍（少陽經上下配穴法），以增強疏解少陽氣機的療效。
