# 毫針刺法—異常情況處理與注意事項
- **來源檔案**：5.1.4毫针刺法—异常情况处理与注意事项.mp4
- **核心主旨**：系統講授毫針刺法臨床常見的五種異常情況（暈針、滯針、彎針、斷針、血腫）之成因、症狀、處理原則與預防，並詳述針刺臨床的安全禁忌與注意事項。

---

## 一、 核心要點精華（Key Summary）
- **理論/診斷要點**：針刺雖相對安全，但若違反操作規範、手法不當或未評估患者狀態，極易引發意外。本講核心在於建立「預防為主，冷靜處置」的臨床安全意識。
- **臨床辨證思維**：處理異常情況需對證施治。例如：因單向撚轉造成的「滯針」，需向反方向退回；因肌肉痙攣造成的「滯針」，則需循按放鬆；「彎針」與「斷針」則嚴禁強行拔針，以防造成更嚴重的組織損傷。
- **高頻重點/考點**：
  1. **暈針的急救處置**（立刻停針、平臥、重者按壓急救穴位）。
  2. **斷針的取出技巧**（切勿移動體位，依殘留部位決定鑷子夾出或外科手術）。
  3. **孕婦禁針穴位**（三陰交、合谷、昆侖、至陰等通經活血穴位）。
  4. **危險解剖區的進針原則**（胸背部、眼區、頸項部風府/啞門等，嚴禁深刺直刺）。

## 四、 刺灸手法與操作規範
- **進針與行針手法**：
  - 行針時要求指力均勻輕巧，**不可單向撚轉角度過大**，以防肌纖維纏繞針體引發「滯針」。
  - 在眼區等特殊部位，不宜大幅度提插撚轉。
- **補瀉手法與留針時間**：
  - 留針期間，**嚴禁患者隨意改變體位**，以防引發「彎針」或「斷針」。
  - 眼周穴位不宜長時間留針，防刺傷眼球或出血。
- **特殊療法（暈針急救）**：
  - 對於重度暈針患者，除拔針平臥外，可選用**艾灸**（百會、氣海、關元）以溫陽救逆，促其恢復。

## 五、 臨床安全、禁忌與異常處理（Clinical Safety）
本講次最核心內容，請務必熟記以下處置規範：

- **異常情況預防與緊急處置**：
  1. **暈針 (Fainting)**：
     - **原因**：初次針刺緊張、體質虛弱、過饑、大汗大泄後、手法過重。
     - **處置**：立即停針並**全部起針**。患者平臥、頭部放低、鬆開衣帶、注意保暖。輕者給予溫開水/糖水；重者指壓水溝、內關、合谷、足三里等，或灸百會、氣海。
  2. **滯針 (Stuck Needle)**：
     - **現象**：針下澀滯，撚轉提插困難，患者感疼痛。
     - **處置**：因單向撚轉者，向**相反方向**將針退回；因肌肉痙攣者，在局部**循按**、彈撥針柄，或在鄰近部位加刺一針以緩解痙攣。
  3. **彎針 (Bent Needle)**：
     - **處置**：**切忌強行拔針、提插或撚轉**。輕度彎曲者慢慢順勢退出；彎曲較大或多處彎曲者，順著彎曲方向逐步分段退出。若因體位改變引起，先恢復原體位放鬆肌肉再退針。
  4. **斷針 (Broken Needle / 折針)**：
     - **處置**：**醫生必須鎮靜，囑患者絕對不可移動體位**（防針體深陷）。殘端露於皮膚外者，用鑷子拔出；殘端與皮膚相平者，按壓針孔兩旁皮膚使之露出後夾出；完全沒入皮下者，需 X 光定位並行**外科手術**取出。預防關鍵在於進針時務必**保留少許針身在體外**。
  5. **血腫 (Hematoma)**：
     - **處置**：微量出血可自行消退；局部腫脹疼痛劇烈者，**先冷敷（止血），後熱敷（促吸收）**。出針時應使用消毒乾棉籤按壓針孔。

- **體質與生理禁忌**：
  - 饑餓、疲勞、精神過度緊張者，應休息進食後再輕手法針刺。
  - **孕婦禁忌**：懷孕 3 個月內禁刺小腹部；3 個月以上禁刺腹部及腰骶部。全孕期禁用通經活血穴位（如合谷、三陰交、昆侖、至陰）。
  - 有自發性出血傾向或凝血功能障礙者，不宜針刺。
  - 局部皮膚有感染、潰瘍、瘢痕或腫瘤部位，不宜針刺。

- **解剖危險區與刺灸深度禁忌**：
  - **小兒囟門未合**：頭頂部穴位不宜針刺。
  - **項部（風府、啞門）**：嚴格掌握角度，禁深刺，防傷延腦。
  - **胸、脅、腰、背部**：內部有重要臟器（心、肺、肝、脾、腎），**不宜直刺、深刺**，防引發氣胸或臟器損傷。
  - **眼區**：注意角度與深度，嚴禁大幅度操作與長時間留針。
  - **小腹部（尿瀦留患者）**：膀胱充盈時，嚴格控制針刺方向、角度與深度，防刺破膀胱。

## 六、 詳細課堂章節筆記
- **[00:00 - 05:00] 異常情況：暈針與滯針**：
  - 講師詳細定義了暈針的先兆症狀（頭暈目眩、面色蒼白、心慌氣短），強調預防勝於治療。對初診患者必須做好解釋工作，首選臥位，選穴少，手法輕。
  - 滯針的處理示範：強調不可強拔，必須找出滯針原因。展示了局部循按放鬆肌肉，以及反向撚轉退針的邏輯。
- **[05:01 - 07:45] 異常情況：彎針與斷針**：
  - 分析彎針常因患者亂動或外力碰撞針柄導致，退針時的唯一原則是「順勢而為」，絕對禁止強行提插撚轉。
  - 斷針是針灸最嚴重的併發症之一。強調針具檢查的重要性，並明示進針深度不可「沒根」，必須預留針身。發生斷針時，醫患雙方均需保持靜止。
- **[07:46 - 10:38] 異常情況：血腫與臨床注意事項**：
  - 血腫的處理原則遵循先冷敷後熱敷的創傷處理常規。
  - 全面梳理了針刺的相對與絕對禁忌症。特別指出了特定生理狀態（孕產婦、嬰幼兒、虛勞者）與特定解剖部位（臟器投影區）的嚴格限制，這是臨床行醫的安全底線。

## 七、 課後複習與臨床實踐建議（Actionable Takeaways）
- **臨床安全記憶口訣**：
  - **部位口訣**：「胸背薄如餅，針刺需謹慎；項部危險區，深刺傷延髓。」
  - **孕婦禁針歌**（供補充參考）：「孕婦不宜平頂針，合谷三陰交莫尋，石門昆侖微至陰，針之落胎若有神。」
  - **異常處理十字訣**：「暈針即停、滯針循按、斷彎勿強拔」。
- **臨床操作建議**：
  1. **初學者習慣養成**：每次進針前，務必以指腹檢查針尖是否有倒勾，觀察針身是否平直。
  2. **溝通與體位**：進針前花 30 秒向初診患者解釋得氣的感覺（酸麻脹重），減輕其恐懼；盡量讓患者在完全放鬆、舒適且能持久保持的體位（多選仰臥或俯臥）下接受治療。
  3. **進針原則**：無論刺多深，針身至少要留 1~2 分（0.1~0.2寸）在皮膚外，這是預防斷針無法取出的最後防線。
