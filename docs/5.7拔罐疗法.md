# 拔罐法（Cupping Therapy）
- **來源檔案**：5.7拔罐疗法.mp4
- **核心主旨**：本講次系統性闡述了拔罐療法的基本定義、常用罐具、多種吸罐操作規範（留罐、閃罐、走罐、抽氣罐），並詳細解析其臨床功效、適應症及安全禁忌處置。

---

## 一、 核心要點精華（Key Summary）
- **理論/診斷要點**：拔罐法是以罐具為工具，藉助燃火、抽氣等方式排除空氣產生「負壓」，使其吸附於體表腧穴或病變部位。其核心病機干預原理在於促使局部皮膚「充血、瘀血」，從而達到溫經通絡、行氣活血、消腫止痛及吸毒拔膿之效。
- **臨床辨證思維**：臨床需依據病情選擇合適的罐法。例如，一般痛症多用「留罐法」；大面積肌肉豐厚處（如背腰部）常配搭潤滑劑運用「走罐法」以大範圍疏通經絡；針對局部寒濕或經絡閉阻，亦可採取「閃罐法」反覆刺激體表。
- **高頻重點/考點**：
  1. **火罐七步操作法**（一點、二塞、三繞、四移、五吸、六留、七取）。
  2. **走罐法的前提**：必須先在體表塗抹凡士林等潤滑劑。
  3. **異常處置**：拔罐所致水泡的處理原則（小泡自行吸收，大泡需無菌刺破放水並消毒）。
  4. **絕對禁忌症**：孕婦腹部與腰骶部、大血管分佈區、皮膚潰瘍及高熱抽搐者禁拔。

## 四、 刺灸手法與操作規範
- **火罐法（留罐）標準七步操作**：
  1. **一點（點火）**：用止血鉗夾取95%酒精棉球，擠去多餘酒精後點燃（防止酒精滴落燙傷）。
  2. **二塞（塞火）**：將點燃的棉球迅速塞入罐底。
  3. **三繞（繞火）**：火在罐底快速繞2-3圈（使罐內空氣均勻受熱膨脹排出）。
  4. **四移（移罐）**：將火退出，迅速將罐平移至患者體表上方。
  5. **五吸（吸罐）**：將罐具扣於體表，使其受負壓吸附。
  6. **六留（留罐）**：留置 5~15 分鐘，或待罐內皮膚出現充血、瘀血即可。
  7. **七取（取罐）**：一手扶罐體，另一手食指按壓罐口邊緣肌肉，使空氣進入罐內，輕輕取下。
- **閃罐法**：前五步同留罐法，但在第六步改為「吸附後即刻將罐取下」，反覆多次操作，直至皮膚潮紅。
- **走罐法**：操作前**必須**於患者皮膚塗抹一層凡士林。吸罐後，術者一手握住罐底，將罐體稍傾斜，前半部微提，後半部著力，用力向前推動。於皮膚表面來回推拉，直至皮膚潮紅。
- **抽氣法操作（四步）**：將抽氣筒套入抽氣罐尾部 -> 移至施術部位並抽氣 -> 留置 5~15 分鐘（或至局部充血） -> 拉起罐尾活塞放氣取罐。

## 五、 臨床安全、禁忌與異常處理（Clinical Safety）
- **解剖危險區與體表禁忌**：
  - 骨骼凹凸不平、毛發較多之處不宜拔罐（易漏氣導致吸附不牢）。
  - 大血管分佈部位絕對禁忌拔罐。
- **體質與生理禁忌**：
  - 皮膚有過敏、潰瘍、水腫者禁拔。
  - 高熱抽搐者禁拔。
  - **孕婦的腹部、腰骶部**為絕對禁忌區。
- **拔罐異常應急處置（起水泡處置）**：
  - **預防**：嚴格控制留罐時間，防止因時間過長或燙傷導致水泡。
  - **小水泡**：直徑較小者無須特殊處理，可讓其自行吸收，避免摩擦破潰。
  - **大水泡**：必須遵循無菌操作。用消毒注射針頭從水泡下緣刺破，放出水液。隨後塗以碘伏或龍膽紫藥水（紫藥水），以防感染。

## 六、 詳細課堂章節筆記
- **[00:00 - 02:07] 拔罐法定義與罐具介紹**：
  - **定義**：利用燃火或抽氣形成負壓，吸附於體表，造成局部充血/瘀血的防治疾病方法。
  - **發展史**：古稱「角法」（最早使用獸角）。
  - **現代常用罐具**：玻璃罐（最常用，便於觀察皮膚顏色）、竹罐、抽氣罐。
  - **火罐物料準備**：罐具、95%酒精棉球（必須擠乾）、止血鉗、凡士林。
- **[02:08 - 04:20] 臨床三大吸罐法實操演示（火罐類）**：
  - 詳細示範「留罐法」七步訣：「一點、二塞、三繞、四移、五吸、六留、七取」。
  - 演示「閃罐法」的快速吸拔與剝離。
  - 演示「走罐法」的推拉技巧，強調凡士林潤滑與提拉角度（稍傾斜，前起後按）的重要性。
- **[04:21 - 05:08] 抽氣罐法演示**：
  - 展示現代抽氣罐的操作，適合懼怕明火或不便使用火罐的場景，操作簡便，分四步完成。
- **[05:09 - 07:05] 拔罐的作用、適應症與安全禁忌**：
  - **中醫機理**：溫經通絡、行氣活血、消腫止痛、吸毒拔膿。
  - **現代醫學機理**：溫熱刺激與負壓促使微血管擴張，改善微循環，促進新陳代謝，調節神經興奮性。
  - **適應症**：極其廣泛。涵蓋外感（感冒、發熱、咳嗽）、痛症（風濕痹痛、肩背腰腿痛）、脾胃病（胃痛、腹瀉）、婦科（痛經）及皮膚神經疾患（蕁麻疹、面癱、中風偏癱）等。
  - **注意事項**：重點強調燙傷預防與水泡的臨床標準化處理。

## 七、 課後複習與臨床實踐建議（Actionable Takeaways）
- **操作記憶口訣**：強烈建議熟記火罐操作七步訣：**「一點、二塞、三繞、四移、五吸、六留、七取」**，這涵蓋了安全與療效的核心動作規範。
- **臨床操作建議**：
  1. **初學者練習**：初期練習火罐時，最易犯的錯誤是「棉球酒精過多」滴落燙傷患者，以及「移罐速度太慢」導致罐內熱空氣冷卻、負壓不足而吸附失敗。建議先在矽膠假人或自己/同伴的大面積平坦部位（如背部膀胱經循行區）練習「三繞」後瞬間「四移、五吸」的連貫性。
  2. **走罐手感培養**：走罐時患者常感疼痛，初學者應注意掌控下壓與推拉的力度，務必確保凡士林塗抹均勻且量足。
