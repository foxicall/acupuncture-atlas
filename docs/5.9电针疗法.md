# 电针疗法（Electroacupuncture Therapy）
- **來源檔案**：5.9电针疗法.mp4
- **核心主旨**：本講次詳細解析電針療法的基本定義、優勢、臨床標準操作流程，以及不同輸出波形（密波、疏波、斷續波、疏密波）的治療規律與安全操作禁忌。

---

## 一、 核心要點精華（Key Summary）
- **理論/診斷要點**：電針是在針刺「得氣」的基礎上，將人體生物電脈衝與針刺刺激相結合的一種療法。其核心優勢在於能**代替人工長時間運針**，且能**客觀控制刺激參數**，確保刺激量的穩定性。
- **臨床辨證思維**：臨床配穴採「主穴」與「輔助穴」搭配。電流刺激強度必須嚴格控制在**「感覺閾」（有麻刺感）與「痛閾」（突發疼痛痙攣）之間**，並根據虛實寒熱及病邪性質選擇相應的波形（如：痛證用密波，痿證用斷續波或疏波）。
- **高頻重點/考點**：
  1. **安全迴路原則**：同一對導線的兩個夾子，必須夾在**同側肢體**的1~3對穴位上，嚴禁電流跨越心臟。
  2. **四種波形的主治對應**：密波（止痛鎮靜）、疏波（治療痿證）、斷續波（提高肌肉興奮性，治癱瘓）、疏密波（促進代謝、消炎消腫）。

## 三、 核心腧穴詳解表
*(備註：本影片重點在於電針儀的操作規範與波形理論，未針對特定單一穴位進行定位教學，故改以文字歸納其配穴與接線原則)*

- **電針配穴與接線原則**：
  - **選穴邏輯**：並非所有處方上的穴位都需要接電針，僅選取起「主要治療作用」的穴位作為**主穴**，以及相應的**配穴**。
  - **正負極接法**：
    - **負極（黑線）**：帶動針體跳動較強烈，一般接於**主穴**。
    - **正極（紅線）**：帶動針體跳動較弱，一般接於**配穴**。
    - *(註：部分現代電針儀不分正負極，或臨床採用交變脈衝，則視儀器設定而定。)*

## 四、 刺灸手法與操作規範
- **進針與得氣要求**：
  - 必須先按常規方法進針，**確保針下產生「得氣」感**（酸、麻、重、脹）後，方可連接電針儀。
- **電針標準操作四步驟**：
  1. **針刺得氣**：常規進針並行針得氣。
  2. **連接導線**：先確保電針儀輸出旋鈕歸零。將同側導線夾子分別夾於主穴（負極）與配穴（正極）的針柄或針體上。
  3. **開機調節**：打開電源，選擇適宜的波形、頻率。**緩慢**調高電流旋鈕，至患者產生舒適的麻刺感（感覺閾與痛閾之間）。留針通電時間一般為 **15～20分鐘**。
  4. **退針順序**：時間到後，**必須先將輸出旋鈕退至「零位」**，再關閉電源，隨後取下導線夾子，最後拔出毫針。

## 五、 臨床安全、禁忌與異常處理（Clinical Safety）
- **解剖危險區與心臟禁忌**：
  - **嚴禁電流跨越心臟**：同一組導線絕不可一端接左側、一端接右側上半身，防止電流通過心臟引發心律失常。
  - **特定部位慎用**：在接近延髓、脊髓部位使用電針時，輸出電流量宜小，絕不可過大。
- **體質與生理禁忌**：
  - 體質虛弱、精神高度緊張者，應注意電流不可過大，以防發生**暈針**。
  - 孕婦慎用電針（避免引起強烈宮縮）。
- **針刺異常應急處置與防範**：
  - **防彎針/折針**：調節電流時切忌「突然大幅度增強」，以免引起肌肉強烈痙攣性收縮，導致彎針或折針。
  - **防觸電**：若電針器最大輸出電壓在40V以上，最大輸出電流必須限制在 1mA 以內。
  - **導電異常防範**：經過溫針灸（艾火燒過）的毫針，表面會產生氧化層，導致導電不良，**不宜用於電針**；若必須使用，夾子應夾在未氧化的針體部分。

## 六、 詳細課堂章節筆記

- **[00:00 - 02:08] 電針療法概述與儀器準備**：
  - 定義與優勢：結合傳統針刺與現代電刺激，省時省力，刺激量客觀可控。
  - 儀器分類：交流/直流可調電針機、脈衝感應、音頻震盪、晶體管電針機等。
  - 配穴核心原則：同側肢體 1~3 對穴位為宜。

- **[02:09 - 06:46] 電針完整操作步驟演示**：
  - 實操重點：進針得氣 -> 儀器歸零 -> 連接正負極 -> 開機選波形 -> **緩慢**調大電流 -> 留針 15-20 分鐘 -> **電流歸零** -> 關機 -> 撤線 -> 起針。影片中多次特寫旋鈕歸零的動作，強調安全性。

- **[06:47 - 07:40] 刺激強度的科學界定**：
  - **感覺閾**：剛開始有麻刺感。
  - **痛閾**：突然產生刺痛或肌肉強烈收縮感。
  - **最佳治療強度**：位於感覺閾與痛閾之間，機體能耐受且有節律性抽動。

- **[07:41 - 09:48] 四大經典波形解析與臨床應用**：
  - **連續波 (Continuous Wave)**：單個脈衝組合。
    - **密波 (Dense Wave)**：高頻 (50-100次/秒)，抑制感覺與運動神經。**主治：止痛、鎮靜、緩解肌肉痙攣**。
    - **疏波 (Sparse Wave)**：低頻 (2-5次/秒)，提高肌肉張力。**主治：治療痿證、韌帶與關節損傷**。
  - **斷續波 (Intermittent Wave)**：有節律的時斷時續 (各1.5秒)。機體不易產生耐受，能強烈提高肌肉興奮性。**主治：痿證、癱瘓（如面癱後期）**。
  - **疏密波 (Sparse-Dense Wave)**：疏波與密波自動交替 (各1.5秒)。克服單一波形耐受，促進氣血循環與代謝。**主治：扭挫傷、關節周圍炎、坐骨神經痛、面癱早期、炎性水腫**。

- **[09:49 - 11:27] 適應症總結與六大注意事項**：
  - 適應症涵蓋痛證、痺證、痿證及神經系統疾病。
  - 重申六大安全守則（檢查儀器、防暈針、防肌肉強直斷針、限制高壓電流、注意針柄氧化問題、避開心臟及中樞神經危險區）。

## 七、 課後複習與臨床實踐建議（Actionable Takeaways）
- **記憶口訣/總結**：
  - **波形選擇口訣**：「痛用密，癱用斷，疏波提肌治痿軟；疏密交替促循環，消腫化瘀效最全。」
  - **操作安全三步曲**：「插線前必歸零，調電量必緩慢，起針前必歸零。」
- **臨床操作建議**：
  - **新手避坑**：最常見的醫療事故是「上次用完忘記把旋鈕歸零」，導致下一個患者一開機就遭受強烈電擊而驚恐或折針。因此，**養成「開機前、關機前檢查旋鈕歸零」是第一要務**。
  - **溝通技巧**：調節電流時，必須全程看著患者的表情並口頭詢問：「現在有感覺嗎？會不會太痛？」一旦患者皺眉或表示刺痛，應立刻往回退一點點旋鈕。
