# 強刺激瀉法

**英文名稱**：Strong Stimulation Draining / Sedation Technique

本頁是圖譜的補充教學整理，供合格專業人員對照來源閱讀。「強刺激瀉法」是本專案對刺激偏重之瀉法的檢索名稱，不是一套所有穴位共用的固定強度處方，也不表示下列穴位一律應強刺激。補瀉定義依北京中醫藥大學公開課件核對；五穴的症狀關聯依本次專案需求與既有課程整理，並保留未經醫療審訂狀態。未取得指定版本《刺灸法學》的原書頁碼，因此不宣稱本頁是該書的逐字摘錄或已核定的臨床標準。

## 一、手法原理與定義校正

- **提插瀉法**：以「輕插重提」區別於補法的「重插輕提」，上提較著重、下插較輕緩。教材以相對較大的幅度、較快的頻率與較長操作時間描述瀉法，不能解讀為越大、越快越好。「緊提慢按」可作動作比較的記憶語，實際刺激量仍取決於部位、體質、病況及耐受。[來源 1、2]
- **捻轉瀉法**：相對補法，其施力、旋轉幅度與頻率較大；須維持受控的雙向交替，避免肌纖維纏繞。**迎隨補瀉是針尖與經脈方向的關係，不能直接寫成「逆經方向單向捻轉」**。[來源 1、2]
- **開闔瀉法**：傳統補瀉課件以退針時搖動針孔、暫不立即揉按描述其與補法的差異；這是手法理論，不能取代消毒、出血處理與必要的止血。[來源 1]
- **得氣與異常針感**：教材常描述酸、麻、脹、重以及感傳。放射感不等於應反覆觸碰神經；突然尖銳、強烈觸電樣疼痛或持續麻木，須停止加重刺激，由操作者評估神經受刺激或損傷的可能。不能把「觸電至足底」當作每次都必須追求的終點。[來源 2、3；安全解讀]

### 本頁不採用的統一數值門檻

需求中提出的「提插幅度 > 3～5 mm」「每分鐘 80～100 次以上」「捻轉角度 > 180°～360°」未在上述通用補瀉課件中被核實為跨穴位、跨病況的標準。本頁不將其寫成最低劑量或自動操作參數，也不把原講義的「分／寸」自行換算為毫米。個別研究或病例採用的參數不能外推成所有人的操作標準。

## 二、臨床辨證與適應情境

瀉法的辨證基礎是實證、實熱等情境，痙攣性疼痛亦須辨別病因和虛實。急性腰扭傷、坐骨神經痛、牙痛、三叉神經痛，以及面癱初期的風熱實證，僅是需進一步辨證的教學情境；症狀名稱本身不決定刺激強度。[來源 1、4、5；本次需求的情境整理]

中國針灸學會的坐骨神經痛資料列有環跳、陽陵泉與委中，且不同療法包含中等強度、平補平瀉等操作；不能概括成這些穴位「臨床均以強刺激瀉法為主」。牙痛資料也以病因處理與個體耐受為前提。本頁不據歷史病例的有效率推定療效保證。[來源 4、5]

## 四、禁忌、預防與停止條件

- 體質極度虛弱、嚴重貧血、妊娠、空腹、過度疲勞或高度緊張者，須先評估並避免直接套用強刺激操作；合谷依本頁列為孕婦禁用。暈針預防與處理依原課程異常處置章節。
- 胸背部及重要臟器、大血管附近，禁止把「強刺激」解讀為增加刺入深度或擴大提插範圍。環跳、陽陵泉、太衝及委中亦有重要神經／血管，不能以「肌肉豐厚」概括五穴的安全條件。
- 出現冷汗、眩暈、噁心、面色改變、劇痛、強烈觸電樣疼痛或持續麻木，應停止刺激並由專業人員處理，不以疼痛程度作療效或得氣成功的指標。
- 刺絡放血的感染、出血風險需獨立評估；開闔補瀉的理論不能取代止血。實際操作限具備相應訓練的合格專業人員。
