# 症狀與針法索引說明

## 操作流程

1. 在圖譜上方選擇「症狀索引」，可先選分科，再點選頭痛、牙痛、失眠、胃痛等標籤。數字表示本教材索引中的穴位數。
2. 3D 圖譜只顯示符合的穴位，鏡頭自動容納整組。綠色為群組穴位，金色為目前選取穴位；其他體側以淡色標記與虛線標籤顯示，可旋轉模型確認體側。「定位整組」可隨時返回群組視角。
3. 點擊模型標記、穴位目錄或抽屜中的群組穴名，查看「主要對應病症」與「手法速查摘要」。點擊病症標籤可再切換到該症狀群。
4. 切換「針法索引」，可依直刺、斜刺、平刺／橫刺、瀉法、補法、平補平瀉、點刺放血或透刺檢索。沒有教材依據的類型顯示 0 並停用；一般瀉法不等於強刺激瀉法。
   「強刺激瀉法」另有環跳、陽陵泉、合谷、太衝、委中五穴的條件式補充教材索引。選取後抽屜會直接顯示該穴的手法原文與注意事項，「閱讀講義」及手機展開全文亦會切換到所選手法的教材。定義校正與資料核對範圍見 `docs/techniques/strong_stimulation_draining.md`；這五穴並非一律適用強刺激。
5. 搜尋欄輸入「牙」或「失眠」，可選單穴直接定位，或選症狀穴位群定位整組。手機和平板先點「搜尋症狀、穴名或代碼」。
6. 手機往上拖曳抽屜把手可展開原始 Markdown；「閱讀講義」與來源按鈕可直接開啟教材。選「全部」或「清除篩選」返回目錄。選取臨床索引會清除經絡與文字條件；選經絡或輸入文字會清除臨床索引。文字搜尋可搭配畫面上顯示的經絡條件；搜尋建議中的症狀群始終指向全圖的完整群組。

## 索引與原文的關係

這些是課程教材的檢索標籤。症狀群包含主穴、對症取穴及辨證加減穴，不表示應同時使用全部穴位，也不表示每個穴位適合所有相同症狀的個案。抽屜中的「查看適用條件與教材依據」保留原列的證型、條件、配穴群記述與來源行號。

`indications` 從核心穴位表的主治文字建立；胃痛、便秘、失眠、偏頭痛、痛經與感冒章節的核心表另保留章節症狀脈絡。僅在散文出現穴名不會自動建立症狀關聯。常用同義詞如齒痛／牙痛、不寐／失眠會歸一化；偏頭痛同時納入頭痛大類。未涵蓋的原始病症仍可在講義閱讀。

`symptomCategories` 為閱讀分科，不是診斷。`techniqueType` 是多選陣列，因同一穴位在不同來源或病況下可能有多種手法。`technique.type` 是主要摘要來源的入針方式；`technique.manipulation` 是有來源的補瀉類型，必須連同適用條件閱讀。原始 `technique.method/depth/safety` 保留不變，不把深度範圍改成單一操作數值，也不推測未載明的補瀉、角度、向量或安全等級。

禁止、未載明與推測性手法不作肯定標籤。群組表列不推定各穴的個別入針方向或透刺路徑；群組補瀉記述則保留共同來源標示。原教材的條件式或補充記述仍須逐項核對。索引與模型都沿用原專案「教材未經醫療審訂、體表位置為示意」的限制。

## 維護與驗證

詞彙、同義詞、分科及來源衍生規則位於 `src/lib/clinical-index.js`。新增標籤時，先核對原講義，再執行 `npm run data:generate` 更新 `acupoints.json`、文件目錄與涵蓋報告。`indicationEvidence` 與 `techniqueEvidence` 保留每個標籤的路徑、行號、原文及配穴群狀態。手動校準只變更幾何資料，不移除索引。

執行 `npm test`、`npm run build` 與 `npm run test:e2e` 驗證來源追溯、無資料分支、鏡頭取景與桌面／平板／手機互動。
