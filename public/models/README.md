# 人體示意模型

`acupuncture_body.glb` 是本專案自行產生的原創、中性人體教學示意模型，無外部模型、貼圖或授權相依。執行 `node scripts/generate-model.js` 可重建相同 GLB 2.0 資產（MIT 授權）。

模型含平滑軀幹、頭面鼻耳、雙臂、手指、雙腿及足部輪廓，全部為參數曲面。它不是醫學掃描，也未經臨床定位驗證；穴位與針向展示只供空間關係教學，不能據此決定人體針刺位置、深度或安全進針路徑。

## 座標契約

- 單位為示意模型單位，不能換算成公分或寸。
- Y 軸向上，Z 正方向為人體正面，X 正方向為觀看者右方（人體左側）。
- 頭頂 Y = 1.8，腳底 Y = -1.8；原點在軀幹中段。
- 肩中心約 X = ±0.48、Y = 0.95。
- 肘中心約 X = ±0.70、Y = 0.30。
- 腕中心約 X = ±0.85、Y = -0.35；手掌延伸至 Y = -0.59。
- 髖中心約 X = ±0.25、Y = -0.25。
- 膝中心約 X = ±0.24、Y = -0.95。
- 踝中心約 X = ±0.24、Y = -1.60；足背向 Z 正方向延伸。

如以臨床審查過的模型替換本檔，必須同時重新校準 `src/data/acupoints.json` 的座標與表面法線；GLTFLoader 不會自動推算或驗證穴位。
